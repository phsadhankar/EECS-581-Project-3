# EECS 581 - Group 20 Project 3

## All-in-one Calculator

**Agile Software Development and Multi-Function Calculator Application**  
University of Kansas | Fall 2026

## About The Project

This project is developed as part of **EECS 581 – Software Engineering II** at the University of Kansas, taught by Professor Hossein Saiedian.

For Project 3, Group 20 is designing and developing an **All-in-one Calculator** using an agile development process. The goal is to combine basic arithmetic, scientific calculations, financial tools, unit conversions, graphing, and other mathematical utilities in one accessible application.

The project is developed with HTML, CSS, and JavaScript. Development is organized into sprints, with each sprint producing working software and preparing requirements artifacts for the next iteration.

## Getting Started

1. Clone the Project 3 GitHub repository or download its files.
    - git clone https://github.com/phsadhankar/EECS-581-Project-3
2. Open `index.html` in a web browser.

No build process or package installation is required.

## Project Documentation

Our project includes 39 requirements. Rather than repeating each requirement in this README, we maintain detailed documentation separately.

- Requirements Artifacts: See the requirements artifacts document in /docs for requirement descriptions, sprint assignments, acceptance criteria, test cases, and recorded implementation/testing status where available.
- Test Evidence: See /evidence for supporting screenshots and other evidence organized by test case or requirement.
- Meeting Logs: See /meetingLogs for records of meetings with our Graduate Teaching Assistant (GTA).

### Sprint Release Deadlines

Development is organized into sprints. Each sprint focuses on implementing selected requirements, reviewing functionality, documenting test results, and preparing the next sprint's requirements artifacts.

### Submission Milestones

- **November 8, 2026:** Sprint 1 Release and Sprint 2 Requirements
- **November 22, 2026:** Sprint 2 Release and Sprint 3 Requirements
- **November 29, 2026:** Sprint 3 Release and Final Sprint Requirements

For each release, the team submits the GitHub repository link, an updated requirements stack, and the next sprint's requirements artifacts. The latest implementation is maintained in the repository's main development files.

## Repository Structure

- `index.html` — Calculator page and controls
- `script.js` — Parser, evaluation, steps, and UI interactions
- `functions.js` - Calculator function definitions
- `styles.css` — Responsive layout and visual styling
- `docs/` - Meeting logs, Architecture and Requirement Artifacts Documents
- `evidence/` - Requirement and test-case evidence
- `meetingLogs` - GTA meeting logs
- `.gitignore` - Git ignore rules
- `README.md` — Project overview

Additional files may be introduced as development continues. Sprint-specific folders or branches are used for organization, but they are not required to understand the main repository structure.

## Testing

The team tests features against the acceptance criteria and test cases in the requirements artifacts. Results and any known issues are recorded in the relevant artifacts, with supporting files stored in /evidence.
